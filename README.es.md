<br>
Este repositorio es el entorno público de entrega web para woodfinegroup.com. Sirve interfaces estáticas compiladas directamente a la web pública y opera un canal de telemetría sin cookies y sin identificadores de sesión, utilizando APIs nativas del navegador. Los datos de los visitantes se recopilan sin información de identificación personal y se enrutan a un relé en la nube con air-gap a través de la Red Privada PointSav.
